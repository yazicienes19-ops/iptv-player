# Keine Passwortabfrage mehr nach Updates

## Was wurde verbessert?

Bisher fragte macOS nach jedem Update nach dem Schlüsselbund-Passwort, weil jede Version eine wechselnde Ad-hoc-Signatur hatte und für den Schlüsselbund wie eine fremde App aussah. Die Mac-App wird jetzt immer mit demselben Zertifikat („IpFlix Signatur“) signiert. Nach dem ersten Start dieser Version und einmal „Immer erlauben“ bleibt die Abfrage bei allen weiteren Updates aus.
