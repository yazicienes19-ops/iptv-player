# Verbindungslimit auf der Downloads-Seite

## Was wurde verbessert?

Die Seite „Downloads“ zeigt jetzt, wie viele gleichzeitige Verbindungen dein Anbieter für dein Konto erlaubt und wie viele gerade belegt sind. Lädt ein Download nur über eine Verbindung, steht der Grund dabei, etwa „Dein Konto erlaubt gerade nur eine freie Verbindung“ oder „Der Anbieter erlaubt kein Laden in Teilen“. So ist erkennbar, ob die Geschwindigkeit vom Anbieter begrenzt wird.
