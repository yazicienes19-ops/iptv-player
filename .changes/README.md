# Änderungen für den nächsten Release

Ergänze für jeden Beitrag eine neue Markdown-Datei direkt in diesem Ordner, zum Beispiel `suche-serientitel.md`. Kopiere dafür die [Vorlage](template.md) und wähle einen eindeutigen Dateinamen.

Beschreibe kurz auf Deutsch, was Anwender jetzt tun können, welches Problem behoben wurde und welche Einschränkungen noch bestehen. Eine technische Änderung sollte erklären, was sie verbessert. Entferne nicht benötigte Abschnitte aus der Vorlage.

Beim nächsten erfolgreich geprüften Push auf `main` übernimmt die Veröffentlichung neue oder geänderte Notizen seit dem vorherigen Release. `README.md` und `template.md` werden dabei ausgelassen. Die Notizen bleiben im Repository erhalten; für spätere Beiträge legst du neue Dateien an. Alte Releases bleiben auf [GitHub](https://github.com/yazicienes19-ops/iptv-player/releases) erreichbar.

Größere Versionen werden zusätzlich im [Changelog](../CHANGELOG.md) zusammengefasst. Die erste Version 1.1.0 hat dort bereits ihre vollständige Beschreibung und braucht keine zusätzliche Änderungsdatei.
